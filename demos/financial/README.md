# Financial Example

Dieser Bereich ist fuer die BuildEngine-Integration des komplexeren Financial-Beispiels vorgesehen.

Das bereits bestehende Repository `adeccscholar/Financial_Example` bleibt eine eigenstaendige Quelle. Die Integration soll es spaeter als echten Consumer des publizierten `Win64x`-SDK-Baums bauen und ausfuehren, statt Library-Smoke-Logik in das Beispiel zu kopieren.

Damit dient das Financial-Beispiel als paketuebergreifende Demo beziehungsweise Integrationsnachweis und nicht als Bestandteil des `ready`-Knotens einer einzelnen Bibliothek.
