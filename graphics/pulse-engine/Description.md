# Pulse Engine — The Shape of Sound

## A sound you can see

An electric-blue control room transforms authentic PCM samples into luminous waveforms. Choose a sine, square, triangle or sawtooth signal; change its pitch and amplitude; inspect the peak and RMS levels and watch the oscillations change instantly. Press **PLAY ON SPEAKERS** only when you want to hear the sound. The native device is never opened in the headless verifier or on application startup.

## Real miniaudio integration

The signal samples are generated by `ma_waveform_config_init`, `ma_waveform_init` and `ma_waveform_read_pcm_frames` in the installed **miniaudio 0.11.26** implementation. The SDL2/ImGui GUI only draws the returned PCM buffer; it never substitutes a mathematically generated sine wave as the alleged miniaudio output.

Optional audible output uses a real `ma_device` callback that reads from the same miniaudio waveform API. The application stops the device before replacing the audio waveform when parameters change. A missing output device is reported in the GUI while visual generation remains available.

## Regression and limitations

`pulse-engine.exe --verify` generates real float samples without opening a device. It checks for finite amplitude, nonzero audio and distinct waveform shapes. Audible quality and Windows device latency require a separate desktop and audio verification.
