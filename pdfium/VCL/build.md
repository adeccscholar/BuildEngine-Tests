# Build — PDFium VCL

Run `cmake -P bootstrap/Bootstrap.cmake` from the BuildEngine-Tests root, then open `pdfium/VCL/PDFiumVCL.cbproj` with RAD Studio 13 and build the **Win64x Debug** or **Win64x Release** configuration. Verify deployed PDFium and Skia runtime DLLs before running. This VCL project is not configured by CMake.
